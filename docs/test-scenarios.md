Учётки: клиент `client@demo.alfa.ru`, сотрудник `manager@demo.alfa.ru`, пароль `alfa2026`.

## Ручная проверка по шагам (основной сценарий)

1. Открыть `http://localhost:8080`, войти клиентом.
2. «Подобрать кредит» → «Оборудование или ремонт» → «Вся сумма сразу» → 3 млн ₽ → 18 мес → залога нет → «Оформить заявку».
3. Нажать демо-компанию `990000000299 · ИП Зерно` → «Всё верно» → «Продолжить» → отметить оба согласия → «Отправить заявку».
4. Трекер: статусы меняются сами каждые ~2,5 с → «Нужны документы» → загрузить любой PDF.
5. Решение: **контрпредложение 2 000 000 ₽ на 18 мес**, видна разбивка балла. «Принять предложение» → отметить согласие с условиями → «Подписать» → «Деньги зачислены».
6. Выйти, войти сотрудником. Создать клиентом заявку на `9900000031` — она появится в очереди ручной проверки; сотрудник делает контрпредложение, клиент видит его в трекере.
