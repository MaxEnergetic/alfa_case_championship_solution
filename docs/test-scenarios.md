# Проверка интеграции

Автоматически: 154 теста бэкенда, 6 тестов gateway и 4 теста JavaScript (команды в README). Покрыты права на чужие анкеты и задания, прохождение дерева, история и исправление ответов, конфликты ревизий, сохранение частичных ответов источников, передача картинки капчи и продолжение того же задания после введённого кода. Тестовые сетевые ответы существуют только внутри тестов, не в приложении.

В браузере: войти, начать подбор, пройти вопросы, указать действительный ИНН, проверить данные и статусы источников, при необходимости вручную ввести капчу. Завершить анкету, посмотреть кандидатов, дождаться автоматической финансовой оценки в общем результате, скачать JSON, перезагрузить страницу и исправить предыдущий ответ.

Для проверки можно использовать публичный ИНН 5505223431. Наличие актуальной выписки/отчётности и доступность ФНС зависят от источников. Проверка не должна утверждать успех, если вернулся partial, CAPTCHA, ограничение или пропуск. Ответы о потребности, введённые для теста, не являются реальными финансовыми сведениями компании.

Недоступный парсер должен давать 503; незаполненная анкета не должна получать рекомендацию; отсутствующая отчётность не должна превращаться в финансовую оценку. В UI и API нет маршрутов подписания или выдачи денег.

Новые проверки: `node --test frontend/app.test.cjs` воспроизводит сохранённый сервером ответ при потерянном HTTP-ответе, проверяет отсутствие второго ввода ИНН, один запрос для двух сумм и один автоматический запуск оценки. `test_credit_experience.py` проверяет атомарный откат неверного блока, поддержку старой версии анкеты, влияние финансового риска на общий итог и отсутствие выдуманной вероятности одобрения.
