# Кабинет клиента и рабочее место сотрудника

Статический сайт без сборки (`index.html`, `app.js`, `styles.css`). Все данные берёт из сервиса заявок через `/api/v1`
(адрес задаётся в `config.js`; для локальной отладки можно открыть страницу с `?api=http://localhost:8003/api/v1`).
В браузере хранится только токен сессии и текущий экран.

В Docker раздаётся nginx (`nginx.conf`), который проксирует `/api` в сервис `applications`. Запуск всего стенда и
сценарии проверки — в корневом [README](../README.md).
