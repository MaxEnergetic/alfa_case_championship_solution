# Интерфейс рекомендаций

Статический HTML/CSS/JS. Запросы идут только в `/api/v1` на том же origin через nginx и авторизованный gateway. Токен и идентификатор текущей анкеты хранятся в sessionStorage; ответы и результаты — на сервере.

Вопросы, варианты и рекомендации приходят из исходного бэкенда. В браузере нет копии продуктовых правил, генератора компаний или искусственного скоринга. Ручная капча загружается через защищённый API как blob; код вводит пользователь.

UI показывает статусы источников, пропуски и конфликты с ответами пользователя. Подписание, выдача, банковское одобрение, рабочее место менеджера и демо-компании исключены из сценария.
